# Security Policy

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Contact the repository maintainers privately using a verified security contact configured by the project owner. Until that contact is configured, do not assume a public address exists. Include affected version/commit, impact, prerequisites, and a minimal reproduction without real personal data.

## Current release status

This repository is an early implementation scaffold, not a security-audited production service. Authentication, tenant isolation, file upload validation, rate limiting, webhook verification, and deployment hardening must be verified before launch. No production credentials or real payment data belong in the repository.
